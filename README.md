# Sales Forecast Management System

## Overview
This project is designed to support the sales team's forecasting activities, accommodating 100 accounts and 10 account managers with functionality for:
- Annual business plan input
- Monthly 6-month forecast input
- Weekly actual sales tracking
- Achievement rate calculations

## Setup Instructions
1. Clone the repository: `git clone <repository_url>`
2. Navigate to the project directory: `cd Sales-Forecast-System`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the application: `streamlit run src/app.py`
